ШАГ 0. ОКРУЖЕНИЕ (проверь и поставь, чего нет)
- Node.js 20+ и npm; ffmpeg + ffprobe в PATH; Python 3.11+ с пакетами numpy, opencv-python.
- Проект Remotion: `npx create-video@latest promo` → `npm i three @react-three/fiber @react-three/drei @react-three/postprocessing @remotion/three`.
- Скиллы, если есть в твоей установке: remotion-best-practices, hyperframes, video-shotcraft, motion-graphics, md-beat-sync-editing, emil-design-eng. Прочитай их SKILL.md до кода.
- Музыка: бесплатный трек с драйвом (например NCS, раздел Phonk / Speed Garage / Tech House). Сохрани в public/music.mp3. В подпись к ролику добавь строку автора трека по условиям лицензии.

ШАГ 1. ИДЕЯ И РАСКАДРОВКА (до кода, файл storyboard.md)
- Одна идея одной фразой: что говорит графика. Ролик = история из 6–10 этапов, каждый этап = свой «мир» с другой фактурой (3D-объект, интерфейс, данные-графики, кинетика форм, таймлайн, телефон с результатом).
- Таблица: время · что в кадре (объект, камера, свет, материал) · движение · переход в следующий этап (каким превращением объекта) · звук.
- Отдельная строка «0–3 с: что видит зритель и почему не пролистает». Кадр 0 — уже событие: знак продукта летит на камеру, а не тёмная заставка.
- Текст в кадре только как часть интерфейса (кнопки, статусы, имена файлов). Никаких карточек-фраз.

ШАГ 2. МУЗЫКА ВЕДЁТ МОНТАЖ (до анимации)
- Напиши скрипт beatmap.py: ffmpeg → моно 11 кГц → огибающая по полосам (бочка < 150 Гц, малый 150–2500 Гц) → автокорреляция → BPM, сетка долей и тактов, самый сильный подъём громкости = дроп. Сохрани beatmap.json.
- Границы этапов ставь на начало такта, каждое превращение, клик, вспышку и толчок камеры — ровно на долю. Дроп = самое эффектное событие ролика.
- Удар в бит делай функцией: нарастание за 4 кадра ДО доли, пик ровно на доле, затухание 0,4 с. Если пик начинается на доле, глаз видит опоздание.

ШАГ 3. СБОРКА В REMOTION
- Каждый этап — компонент, вся анимация — функция от useCurrentFrame() (никаких setTimeout и state): так любой кусок рендерится одинаково.
- Кривые: появление cubic-bezier(0.23,1,0.32,1), движение по экрану (0.77,0,0.175,1). Прозрачность — smoothstep, переходы не короче 0,5 с.
- Интерфейс премиальный: стекло с backdrop-blur и тонким бликом по кромке, сетка 8 px, одни радиусы, одна библиотека иконок, моно-шрифт для цифр, мягкие многослойные тени. Никаких серых прямоугольников-заглушек.
- 3D (знак, шары, частицы) — three.js внутри Remotion: MeshPhysicalMaterial (clearcoat), мягкий ключевой и контровой свет, bloom, глубина резкости. Логотипы — официальные SVG, выдави через SVGLoader + ExtrudeGeometry.
- Камера живая всегда: облёт, наезд, параллакс слоёв, толчок на сильной доле. На каждом такте меняется масштаб или ракурс.
- Шрифты вшей в проект (base64 или локальный файл), чтобы рендер не ждал загрузку.

ШАГ 4. ХУК ОТДЕЛЬНО
- Отрендери только первые 4,5 с в двух вариантах. Посмотри кадры 0,0 / 0,5 / 2,0 / 2,5 / 4,4 с в полный размер: ничего не срезано краем, знак не ребром, движение есть в каждой полсекунде. Слабый хук переделай до сборки тела.

ШАГ 5. ЧЕРНОВИК БЕЗ ЗВУКА И ПРОВЕРКИ КОДОМ
- `npx remotion render <Composition> out/draft.mp4 --codec h264 --pixel-format yuv420p`.
- Напиши и прогони checks.py (OpenCV): склейки в секунду (разница гистограмм соседних кадров выше порога) — норма до 0,7/с; застывшие кадры (3+ одинаковых подряд) — 0; доля светлых кадров ≤ 45 %; хотя бы один непрерывный план ≥ 4 с.
- Лист кадров 6 к/с (`ffmpeg -vf fps=6,scale=360:-1,tile=6x6`) — просмотри глазами каждый: нет пустых тёмных кадров, срезов, наездов текста.
- Синхрон: для каждого события из раскадровки найди ближайшую долю из beatmap.json, расхождение ≤ 1 кадр. Таблица в отчёт.
- Полных рендеров не больше 2. Правки — рендером только изменённого куска (`--frames=a-b`) и вклейкой по кадру через ffmpeg.

ШАГ 6. ЗВУК
- Трек + мягкий эффект (whoosh, стекло, клик) на каждое видимое событие, ни один файл эффекта не повторяется, эффекты на 6–10 дБ тише музыки. Фейд музыки 1,5 с на последней фразе, конец на сильной доле.
- Сведение ffmpeg, итог `loudnorm I=-14:TP=-1`, проверка `ffmpeg -af ebur128`.
